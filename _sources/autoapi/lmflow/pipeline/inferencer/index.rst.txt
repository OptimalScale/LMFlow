   .. py:method:: score_to_prob(scores: torch.Tensor, temperature: float = 0.0, top_p: float = 1.0) -> torch.Tensor
      :staticmethod:


      Convert scores (NOT softmaxed tensor) to probabilities with support for temperature, top-p sampling, and argmax.

      :param scores: Input scores.
      :type scores: torch.Tensor
      :param temperature: Temperature parameter for controlling randomness. Higher values make the distribution more uniform,
                          lower values make it peakier. When temperature <= 1e-6, argmax is used. by default 0.0
      :type temperature: float, optional
      :param top_p: Top-p sampling parameter for controlling the cumulative probability threshold, by default 1.0 (no threshold)
      :type top_p: float, optional

      :returns: Probability distribution after adjustments.
      :rtype: torch.Tensor
